# RAIO nas Escolas — Trilha Digital para Jovens

Site estático em HTML, CSS e JavaScript puro com finalidade educativa, preventiva, institucional e cidadã, voltado a adolescentes. O conteúdo foi estruturado a partir do material institucional do CPRAio presente neste projeto, com adaptação de linguagem para uso didático e sem reproduzir trechos longos literalmente.

## Objetivo

Explicar de forma clara e acessível:

- o que é o RAIO/CPRAio;
- como agir com segurança e respeito durante uma abordagem policial;
- direitos e deveres básicos do cidadão;
- riscos e responsabilidades no ambiente digital;
- caminhos para ingresso na PMCE e posterior acesso ao CPRAio;
- valores esperados de quem deseja seguir carreira policial militar.

## Estrutura de arquivos

- `index.html`: estrutura da cartilha digital.
- `styles.css`: identidade visual, layout responsivo e animações leves.
- `script.js`: navegação mobile, quiz, botão de voltar ao topo e efeitos de entrada.
- `Geral - Apresentação Institucional CPRaio.pdf`: material institucional usado como base temática.

## Como executar

1. Abra a pasta do projeto no navegador de arquivos.
2. Dê duplo clique em `index.html`.

Alternativa com servidor local:

```bash
python3 -m http.server 8000
```

Depois, acesse `http://localhost:8000`.

## Observações importantes

- O site foi produzido para publicação estática e não depende de bibliotecas externas pesadas.
- Os números institucionais inseridos na seção “RAIO em números” foram extraídos do PDF local e receberam comentários no código para revisão antes da publicação oficial.
- Antes de publicar, é necessário validar com a instituição:
  - quantitativos atualizados;
  - nomenclaturas oficiais vigentes;
  - regras atuais de ingresso na PMCE;
  - qualquer informação institucional que possa ter sido alterada após o material-base.
- O conteúdo evita detalhes operacionais sensíveis e mantém foco estritamente educativo e preventivo.
